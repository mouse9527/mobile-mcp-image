# 看界面、手机被别人动过、熄屏

## 读元素和截图

- **读元素** = `mobile_list_elements_on_screen`：列出屏幕上的元素，带 `@ref`、文字、坐标。**截图** = `mobile_take_screenshot`：截一张图给自己看 / 给用户看
- **通常先读元素**，按返回的 `@ref` 点。元素里有文字、按钮、输入框里的当前内容，很多卡片的 `label` 已经把「标题 + 价格 + 销量 / 评分」拼在一起，直接读它最准；价格被拆成一位一个的小节点时，读父节点的 `label`
- **截图用在这些时候**：元素里找不到要点的东西；要看图片里的内容（商品图、菜品图里的字、验证码）；要给用户看结果；元素和预期明显对不上，或返回的几乎只有状态栏 / 底栏
- 参考 2026-10-20 实测：京东首页 / 搜索 / 结果 / 商品页 / 秒送、淘宝首页 / 搜索 / 结果 / 商品页、美团首页 / 搜索结果 / 外卖店铺页、点评都能读到；**读不到的**：京东和淘宝的购物车、淘宝闪购的店铺列表、美团小象超市（小程序）——这些页面直接截图
- 按截图点时，用截图结果里附带的坐标换算说明换成屏幕坐标，再点击屏幕传 `x` / `y`；估坐标容易点错 tab、点到浮窗，能用 ref 就用 ref
- 页面在加载：再读一次元素 / 再截一次图（手机服务没有专门的等待工具）

## ref 会漂移

`@ref` 是「读元素时第几个节点」，点击时会**重新读一次界面再按编号找**。页面上有倒计时、轮播、刷新中的信息流，或者状态栏图标变了，编号会整体偏几位，点到旁边的东西（参考 2026-10-22：拼多多同一静止详情页 10 秒内「分享」按钮编号在 @e156 / @e164 / @e172 之间跳；分享面板里按 ref 点「复制链接」点成了「分享图片」）。

所以**旁边挨着危险项的按钮不按 ref 点，按坐标点**：用刚读到的元素给的中心点 `c=x,y` 直接点，或截图换算。典型：分享面板（旁边是联系人 / 各分享渠道）、拼多多「分享到拼小圈 | 分享」、底栏购买按钮旁边的按钮。普通的 tab、搜索框、商品卡用 ref 没问题，点完看结果对不对。

分享面板只点「复制链接」，点前截图核对，点完读剪贴板确认；生成海报 / 保存图片、「分享领红包」都不点。

## 手机可能正被别人用着

手机排队只能挡住别的对话 / agent 的调用，挡不住**用户本人**在动手机。每次读到界面时，和**自己上一步离开时**对一下：

| 读到的 | 多半是 | 怎么办 |
|---|---|---|
| 弹窗、广告、红包、开屏页、「已进入防误触模式」，关掉后还是原来那个 App 和页面 | App 自己弹的 | 关掉继续 |
| 自己点了之后跳到了别的页 / 别的 App（例如点商品打开了小程序） | 自己这一步引起的 | BACK 回来继续 |
| 熄屏 / 全黑 | 见下一节 | 手机服务会自动点亮 |
| **任务刚开始**，打开 App 落在以前留下的页面（别的店、旧搜索词） | 热启动回到上次停留的页面，正常 | 回首页或直接从这里开始 |
| **前台换成了一个自己没打开过的 App**；页面不是自己打开过的；输入框里有不是自己输入的文字；购物车 / 地址变了 | **可能有人在用手机** | **停下**，不要继续点，也不要把 App 切回来。`lease_release` 后回复用户「手机好像正被别人在用：我上一步在 X，现在前台变成了 Y。等那边用完再叫我」 |

拿不准时宁可停下问一句。**不要用启动 App 的能力把自己的 App 切回来「试一下」**——对面如果还在用，这一下就是在抢。

重新拿到手机、或者隔了很久（例如上一轮之后）才继续：**先读一次元素或截图确认界面**。

## 熄屏

手机**经常是熄屏的**，但**不用你处理**：手机服务在每次需要屏幕的操作之前会自己点亮屏幕、解除「防误触」，然后再执行。

- **不要按 POWER**（它是开关，亮着时一按就熄），也不用为了唤醒去按 HOME / 音量键
- 结果说「**手机屏幕没能自动点亮或解除遮挡**」：手机可能被扣着 / 被挡住，告诉用户需要人看一眼，等用户处理后再继续，不要自己反复试
- 点亮后截图仍全黑、元素只剩状态栏：多半是页面在跳转 / 加载（再读一次），或者是安全页面（`captcha`）
