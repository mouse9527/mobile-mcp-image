# 输入文字

参考 2026-10-20 实测：手机的输入法（中文模式）会把**纯英文 / 数字**的输入当拼音组字（「airpods pro 3」进框变成乱码，「airpodspro3」只剩「3」）；**只要文字里有一个中文字，就会原样进去**（「苹果AirPods Pro 3」「苹果降噪耳机第三代」都一字不差）。

- 点输入框；框里有旧内容先清空（找「×」/「清空搜索框中内容」之类；别点成「清除历史记录」——那是删搜索历史）。不清空的话新文字会接在后面
- 关键词**尽量带上中文**（「苹果AirPods Pro 3」比「airpods pro 3」可靠）
- 输入之后**读一次元素，看输入框里的字对不对**（输入框的 `text` / `value` 就是当前内容）
- 不对：清空重输一次；还不对就点联想词 / 历史搜索里合适的那条。同一个关键词别反复试超过两轮
- **输入后框还是空的**（中文是靠剪贴板粘贴进去的，个别 App 的输入框不接，参考 2026-10-21 闲鱼搜索框）：点开键盘工具栏的**剪贴板**面板，点刚才那条文字插入，再读元素核对。剪贴板面板只用来插入，不删条目、不改输入法设置
- **提交后核对搜索真的生效了**：读一次元素看结果页顶部的关键词是不是这次输入的、输入框里有没有残留旧词。还要看**是不是在店内搜索**：从店铺页进去的搜索框只搜这一家店（结果页出现「没有找到更多商品，为您推荐本店其他商品」就是店内）——要全站搜索，先 BACK 回首页或结果页，再用顶部搜索框
- 批量执行里**不能放截图**（会报错）；要在批量执行里看结果，用它的「结束时读元素」选项（`listElementsAtEnd`）
- 不要用 `mobile_save_screenshot` 把截图存到手机里（存到哪都不给用户看）；给用户看用截图
