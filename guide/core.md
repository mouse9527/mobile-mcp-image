# 手机使用说明（核心）

用手机服务操作用户的真手机之前先读这一份；细节按需用 `phone_guide(topic=…)` 读（列表在末尾）。

手机服务操作的是服务端为当前用户绑定的那部真手机，App 里登录的是用户本人的主账号：不要猜、切换或尝试别的设备 / 账号。每一个点击都是真的（会进购物车、留下浏览记录、触发风控），只做用户要求的事。手机是否在用户身边、能不能收短信，以系统提示里的「设备事实」为准；没写就当用户碰不到手机。

用手机做的：淘宝 / 天猫、京东网购，闲鱼二手，微博（只读），外卖与即时零售（美团外卖、美团小象超市、淘宝闪购、京东秒送），大众点评 / 美团到店，拼多多（只读比价）。一次只做一个任务，不在两个 App 之间来回切。

## 硬规则（不能变通）

- **不提交订单、不付款**：不点「立即购买」「立即抢购」「去支付」「提交订单」「确认支付」。到这一步就停，截图给用户，请用户自己在手机上确认。进了结算页不用批量执行，一次只点一下，点前看清。
- **手机任务只用手机服务**，不改用浏览器或别的服务。
- **同一个验证最多 3 次**；短信验证码、人脸、「账号存在风险」、登录交给用户（`captcha`）。
- **不打开链接（deep link）**，美团系一律不用；任何时候都不打开支付 / 拨号类链接：`alipays://` `alipay://` `weixin://` `wxpay` `tel:` `sms:` `intent:`。
- **不用手机定位**、不改系统定位，定位授权弹窗选拒绝。
- **拼多多只读比价**：不拼单、不下单、不领券、不先用后付、不助力分享。
- 不新增 / 编辑 / 删除收货地址、不设默认（在已保存地址之间切换可以）；不删除 / 取消订单；不改账号、隐私、支付设置；不开通会员。
- 不点广告和「打开 XX App」类跳转，不点「领」红包 / 券（用户要求除外）；不发评价、私信，不联系商家 / 骑手（用户明确要求且先确认内容除外）。
- **分享面板只点「复制链接」**：联系人和各个分享渠道都不点（点联系人就是直接发给真人），按坐标点、点前截图核对（`screen`）。
- 不装、不卸 App，不改系统设置（用户明确要求除外）。

## 怎么做

1. 列一次设备拿 device id，后面一直用它；列表里没有设备就停下告诉用户，不要试别的 id。
2. 打开 App（包名见 `app:<名>`）后先看是不是验证页 / 弹窗，再从首页搜索框搜；用筛选 / 排序，不一屏屏滚。
3. 看界面**先读元素**（`mobile_list_elements_on_screen`），按 `@ref` 点；要看图、元素里找不到、要给用户看结果时才截图。旁边挨着危险项的按钮按坐标点（`screen`）。
4. 「动作 + 看结果」、一串不用中途判断的动作，放进一次批量执行，结束时读元素（`speed`）。
5. 输入文字后读元素核对输入框里的字（`input`）。
6. 读到的界面和自己上一步离开时对不上（前台换成自己没打开过的 App、输入框里有不是自己输的字、购物车 / 地址变了）：**停下**，不要切回去抢，告诉用户手机好像正被别人在用（`screen`）。
7. 手机常熄屏，手机服务会自动点亮：不要按 POWER；结果说没能点亮，就告诉用户需要人看一眼。
8. 收尾：说清停在哪一页、备好了什么，附关键截图；收起键盘 / 筛选面板 / 浮层（`BACK`）；不退出 App、不清空购物车；中途放弃的退回 App 首页。

## 一轮内做完，回复前释放手机

- 手机同一时间只给一个任务用：调用手机工具会自动占住手机，别人排队。每次调用后占用只保持约 {{LEASE_IDLE_S}} 秒。
- **一口气做完再回复**：不要发「我先看一下…」「接下来我去…」就结束这一轮——回复一发出，这一轮就结束了。只在这些时候停下回复：做完了；需要用户决定；需要用户本人操作（登录、短信、扫码、付款、验证 3 次失败）；碰到硬规则。
- **回复之前调用 `lease_release`**，任务失败或放弃也一样。下一轮再用手机会重新占用。
- 要用户扫码 / 看验证码 / 登录 / 回复你：**先 `lease_release` 再回复**；用户回来后的下一轮重新拿手机，先读一次界面确认没被动过。
- `lease_hold` 只用于**同一轮里**等用户在手机上点一下（最多 {{LEASE_HOLD_MAX_S}} 秒），不要用它跨轮留着手机。
- 用户说「我在用手机」「先别动」：这一轮不再操作手机，`lease_release` 后如实告诉用户：手机服务不能长时间替他挡住别的对话。
- 调用结果说手机被另一个任务占用、你排第几：不要换别的办法做同一件事，也不要连续快速重试；等半分钟到一分钟重试同一个操作（每次最多排队等约 {{LEASE_WAIT_S}} 秒），或告诉用户手机正被占用、问要不要等。`lease_status` 能看是谁在用、你排第几。
- 你派出去的子 agent 和你算同一个使用者：手机操作不要并行分给多个子 agent。

「购物通用」「外卖（手机）」「用户位置」这几份说明不在手机服务里：你的环境里有就照着用（价格判断、外卖共性、收货地址）。
